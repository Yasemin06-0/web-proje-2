# web-proje-2# Yapay Zeka Araçları Rehberi (BPR201 - Haftalık Proje Ödevi 2)

## Proje Amacı
Bu proje, farklı alanlarda kullanılan beş temel yapay zeka uygulamasını (ChatGPT, Midjourney, GitHub Copilot, Notion AI, Perplexity AI) çözdükleri sorunlar ve somut kullanım örnekleriyle tanıtan, başlığa göre anlık arama yapılabilen 3 sayfalık bir web sitesidir.

## Çalıştırma Adımları
1. Proje dosyalarını bilgisayarınıza indirin veya GitHub Codespaces üzerinde açın.
2. Terminalde `python3 -m http.server 8000` komutunu çalıştırın veya `index.html` dosyasını doğrudan bir web tarayıcısında açın.
3. Üst menüden **İçerikler** sayfasına geçerek başlık arama özelliğini test edin.
